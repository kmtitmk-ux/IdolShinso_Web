# 執筆の方針

- 読者コメントの傾向(熱狂・期待・不安・批判・比較・諦めなど)を根拠に、ファンが何を求め、何に引っかかっているのかを読み解くこと
- 「何が起きたか」の説明で終わらず、「なぜファンはそう感じるのか」を一段深く掘り下げること
- 深層心理や市場評価は「仮説」として扱い、「〜と読み取れます」「〜ではないでしょうか」の形で書くこと。断定しないこと
- グループ(カテゴリー)間の対比も交え、今のアイドルシーン全体の空気が見えるようにすること
- 読者が「確かにそうだ」「それ、感じていた」と思える具体的な切り口を、冒頭と結びに必ず入れること
- 取得データに書かれていない数値、順位、日付、出来事は絶対に書かないこと。数字は、データに明記されているものだけを使うこと
- 考察と解釈は積極的に行うが、事実と仮説を混同しないこと
- コメントを引用する場合は、言い換えや要約にとどめ、投稿者が特定できる表現やユーザー名は使わないこと
- データが少ないグループは、無理に水増しせず短くまとめること。「傾向は限定的ですが」と一言添えること
- 画像URLがデータに含まれている場合のみ、考察の流れに合う箇所に <figure><img> として自然に配置すること。URLを推測で作らないこと
- 一つの文章はなるべく短くして<p>で段落を変える


## 1. 生成するコンテンツ

以下の2項目を生成してください。

- title：クリック率（CTR）を重視した記事タイトル
- content：有料記事として公開する本文。HTML形式で記述する

2項目は同じ記事を構成する要素です。タイトルで興味を引き、冒頭で面白さを伝え、本文で期待に応える構成にしてください。


## 2. title：クリック率（CTR）を重視したタイトル

タイトルは、読者が記事をクリックする理由を明確に感じられるものにしてください。


### タイトルの方針

- 今週のアイドルシーンで見られた特徴的なファン心理、評価の変化、グループ間の対比など、最も興味深い切り口を選ぶ
- ニュースの羅列ではなく、「なぜそうなっているのか」「ファンは何を感じているのか」が気になるタイトルにする
- 具体的なグループ名や話題が重要な場合は、可能な限りタイトルに含める
- 読者が自分の推しグループやアイドルシーンについて考えたくなる表現を使う
- 本文で実際に深掘りする内容とタイトルを一致させる
- 過度な煽り、根拠のない断定、誤解を招く表現は避ける
- 「今週のアイドルシーン考察」のような定型的で抽象的なタイトルだけにしない
- タイトルのために、取得データにない出来事や評価を作り出さない
- タイトルの長さは原則28〜40文字程度を目安とし、自然さと訴求力を優先する
- タイトルに期間を入れる場合は、必要に応じて本文やサイト側の表示と役割を分ける


### タイトルの考え方

次のような切り口を、取得データに応じて使い分けてください。

- ファン心理：「ファンはなぜ〇〇にこだわるのか」
- 評価のギャップ：「話題性とファンの評価に見える温度差」
- グループ間の対比：「同じ出来事でも評価が分かれる理由」
- 期待と不安：「期待が高いからこそ、不満も生まれる」
- 市場評価：「ファンの反応から見える、グループの現在地」
- 潜在的な論点：「コメント欄で繰り返される、ある違和感」

これらは例であり、毎回同じ型を使う必要はありません。取得データから最も強い切り口を選んでください。


## 4. 冒頭の文章

ゲストユーザーが閲覧できる部分となる

### 冒頭の方針

- 本文の冒頭や、最も興味を引く考察の一部をもとに作成する
- 今週のアイドルシーンにどのような違和感、対比、意外な傾向があるのかを具体的に伝える
- 読者が「なぜそうなるのか、続きを読みたい」と感じる問いや論点を残す
- 本文に存在しない事実や、本文で扱っていない考察を追加しない
- タイトルの言い換えだけで終わらせない
- 記事の結論や重要な分析をすべて明かさず、続きに読む価値を残す
- 不自然な煽りや、過剰な購入誘導は避ける
- 本文の文章を抜粋する場合は、前後の文脈が自然につながる範囲を選ぶ
- 文字数は400〜700文字程度を目安にする。本文の内容やデータ量に応じて調整してよい


## 3. content：有料記事の本文

1. `冒頭の文章、ゲストユーザーでも閲覧可能
2. `<h2>今週({{weekStart}}〜{{weekEnd}})のシーン考察</h2>` 全体の空気感を3〜4文で述べる。読者の関心を引く切り口から始めること
3. グループ(カテゴリー)ごとに、次の構造で出力する。データが十分に読み取れるグループを中心に、3〜6個程度選ぶこと
   `<h2>[グループ名]</h2>`
   `<p>` ファンの声から見える今の状況を1〜2文で示す `</p>`
   `<p>` コメントの傾向から読み取れるファン心理と、市場からの評価についての考察(250〜350文字) `</p>`
   (画像がある場合のみ)`<figure><img src="[画像URL]" alt="[グループ名]関連画像"></figure>`
   `<ul><li>話題になっていた記事や話題のポイント</li></ul>`
4. `<h2>今週の注目グループ</h2>` 最も熱量や議論が感じられたグループを深掘りする
5. `<h2>編集部の視点</h2>` 今週全体のトレンドと、来週に向けた展望を述べる


## 4. 出力形式

必ず以下のJSON形式で出力してください。

{
"title": "記事タイトル",
"content": "冒頭の文章<h2>今週の考察</h2><p>本文...</p>",
}

### content出力形式の制約

- `<body>` の中身のみ出力すること(`<!DOCTYPE>` や `<html>` タグは不要)
- です・ます調で統一すること
- 記事全体で3000〜5000文字程度(データ量に応じて調整してよい)
- コードブロックや ``` は使わず、HTMLタグをそのまま出力すること
